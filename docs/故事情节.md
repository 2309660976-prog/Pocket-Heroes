# Pocket Heroes 故事情节：长路与两岸

> 项目：E:\Pocket Heroes。其他会话设计关卡时先读本文和 `.handoff/story.md`。
> 当前方向：奇幻冒险为主，使者出使为贯穿线索。每章独立成篇，每章十个关卡；战斗推动相识、合作与误会变化，最终与皇室成员交战，战后交流解除核心误会。
> 下文暂定十二章、一百二十关。章节数量、人名和国名属于可继续调整的创作提案；不是已实现的游戏功能。本文取代此前以水闸调查、外交听证为重点的方案，后续不要混用旧章节编号。

## 一、完整故事梗概

澜川国的年轻使者沈砚，带着国书与一枚刻有太阳的古老信物，前往海另一侧的砺原王国。他的任务是在四十天后的双月庆典之前，邀请对方皇室续订已经中断多年的商路与互助盟约。如果错过庆典，王国议会将通过边境封锁，山地村镇会在冬季前失去粮盐贸易。

沈砚以为这是一次漫长但体面的旅行。出发第三天，他就在森林里被哥布林抢走包裹；后来被狼群困在旧猎场，被边防士兵当成盗宝者追捕，乘船后又遭海盗劫持。他不得不与森林猎手、哥布林修补匠、逃兵和女海盗合作，每走过一个地方，就多一位能帮上忙、也可能把麻烦带进下一章的朋友。

麻烦的源头之一，正是那枚太阳信物。它确实由澜川外交署交给沈砚，却属于数十年前两国王室共同保管的航路钥印。砺原王室此前遗失了另一件外形相似的礼器；边境流传的通缉画把两者混为一谈。更糟的是，使团原定走北方官道，遭袭后改走南方森林与海路，沿途留下的记录听起来越来越像一伙武装盗宝者：与哥布林同行、袭击岗哨、乘海盗船、潜入旧王陵。

砺原公主伊蕾娅奉命追回失物。她沿着残缺报告追来，几次只看到战斗结束的现场。沈砚也根据追捕者的王室徽记认定，公主故意阻挠和平。两人并非从没尝试解释，而是每次都有身份核验失败、突发危险或新的可疑行为打断交流。双方逐渐把自卫理解为心虚，把救人理解为收买人心。

穿越暴风海、沼泽和古城后，队伍终于来到砺原王城。公主为了避免庆典现场受袭，在宫外拦住他们，要求交出信物并接受拘押。沈砚担心同伴被当成盗匪处决，拒绝立即缴械，双方展开最后一场战斗。

战斗以彼此失去决定性优势结束：沈砚放弃趁隙夺取公主的性命，转而救下坠落的近卫；公主也命令弓手停射，救出被碎石压住的使者。局势终于允许两方坐下来，把国书、信物、追捕画、沿途见证和各自收到的命令逐一对照。他们发现彼此追的、护的根本不是同一件东西，所谓敌国武装入侵，其实是一支被赶离官道、拼命赶来谈和平的使团。

误会解释清楚后，仍有实际损害需要赔偿、真正的盗宝团伙需要追查、边境村庄需要援助。皇室安排正式接见，沈砚完成续盟。最后大家围坐长桌，从森林里丢掉的一袋干粮开始讲述旅途，公主听到一半才发现，自己几次追击竟然帮他们赶跑过真正的敌人。

## 二、奇幻与真实感如何共存

- 世界里有哥布林、巨狼、巨蛛、沼泽怪、遗迹守卫与有限魔法。它们各有栖息地、食物来源或守护职责，不会为了凑战斗随意出现在所有地图。
- 魔法能点亮符文、治疗轻伤、操纵少量元素；不能随意传送、复活或鉴定所有谎言。强力施法需要准备与体力。
- 哥布林有掠夺者，也有工匠和家庭；海盗有真正杀人越货的恶徒，也有被迫私运的船员。解除误会不代表所有敌人都变成好人。
- 野兽的冲突以饥饿、护幼、领地或人为驱赶为原因，主要通过脱离危险、关闭通路或驱退解决；不安排打完狼后让狼开口解释。
- 杀伤性敌人允许严肃战斗；普通守卫、误认身份的角色和最终皇室战以击退、缴械、失去战斗能力为胜负，不能前面杀光近卫，结尾一句误会便欢笑收场。
- 战后交谈短而具体：先处理伤员、交换一个新事实，再决定下一步。大部分游玩时间留给探索、战斗、救援和合作。
- 不是每章都有幕后阴谋。有些麻烦只是暴雨、饿狼、缺钱或陌生地方的规矩；真正盗宝者只利用其中部分机会。

队伍可按章节更换助战角色：林荻擅长林地，咕鲁擅长机关，玛琳负责海路，阿朔理解边关。角色离队有明确去向，之后可在重聚时回归。是否可操作同伴由游戏实现决定，剧情不强制切换操控。

## 四、紧迫感与误会主线

### 四十天的旅程

第1—3章用十二天，第4—6章用十天，第7—9章用十天，第10—12章用八天，最终在第四十日庆典开幕前抵达。天数包含航行、休整和章间赶路；不默认做实时倒计时，失败重试不消耗剧情日期。

紧迫感通过三个阶段递进：开始是错过渡船就要等七天；中段是通缉令已先到下一个港口；末段是王城将封闭庆典道路，必须在最后一夜越过山口。每章给出眼前可感知的压力，不让所有敌人都喊世界即将毁灭。

### 双方为什么一直没说清

1. 正常外交通知按北方官道送达，南方基层守卫没有使者画像；证件可以申请核验，但往返需要时间。
2. 第三章国书外匣受损，外层通行封蜡毁坏，内层国书与任命书仍完整。其真伪需要王城保管的副验确认，基层不能凭陌生徽章放行武装队伍。
3. 主角每次逃走都有当场理由：同伴正被错误扣押、真正强盗混在追兵后面，或灾害迫使队伍转移。逃跑同时客观加重怀疑。
4. 主角尝试送信：第五章托港署发出的说明，经第十章查明被瓦伦截走；第九章第二次说明走官方渠道，最终在第十二章抵达。不能全靠角色忘记写信拖剧情。
5. 王室公主只掌握“失物画像＋冲突记录”，主角只掌握“王室追兵＋被封道路”。每次新事实先改变局部判断，最后才能拼出整体。
6. 第十章抓住瓦伦后，主角拿到证据，但王城远端军令尚未撤销；必须实际送到能核验、能下令的人手里。最后冲突不靠公主拒绝看所有证据，而是双方都要求先得到安全保证。

## 五、十二章与每章十关

每章拥有独立环境、主要敌人、当地人物、一次关系变化和完整小结。下面编号采用 `CH01-01` 格式；它们是关卡设计骨架，正式制作时再扩展地图、敌人数量、机关与对白。

### 第一章 CH01：林间丢失的国书（第1—3日）

使团离开临川，走林间驿道赶第一班渡船。哥布林趁营地混乱偷走装国书的包裹，主角追进森林，才发现它们以为这是收税队抢走的过冬物资。部落里确有惯偷，最初的偷窃仍需归还与赔偿。

| 关卡 | 场景、战斗与事件 |
| --- | --- |
| CH01-01 城外驿道 | 赶走抢车的小型野怪，学习移动和近战；交代渡船时刻 |
| CH01-02 黄昏营地 | 哥布林偷走包裹，阻挡佯攻者，追踪真正携包者 |
| CH01-03 蘑菇林 | 应对投石手与遮挡视野的巨菇，找到被丢下的使团绶带 |
| CH01-04 倒木溪 | 哥布林割断简桥，边抵挡追兵边找浅滩过河 |
| CH01-05 绳网陷阱 | 救出倒吊的咕鲁，发现他也被同族掠夺者拿来顶罪 |
| CH01-06 空粮车 | 打退抢粮野猪，看见部落被征走的空粮袋 |
| CH01-07 树根小寨 | 突破尖刺与盾兵，守住出口，避免火把烧到居住区 |
| CH01-08 错拿的包裹 | 夺回相似包裹，却只有粮税清单；得知国书在寨主手里 |
| CH01-09 寨门争执 | 与坚持不还包裹的护寨队交战，咕鲁护住部落孩子 |

**章末**：咕鲁送出一枚铜铃作辨认信物，暂留部落处理赔偿。误会解除，部落仍不完全相信官军。沈砚学会先问敌人以为自己是谁。

驿桥关闭，队伍绕行旧猎场。林荻把使团运输箱误认成盗猎笼，与队伍发生冲突；真正危险是狼群被盗猎火线赶入峡谷。环境与动物行为成为主角。

| --- | --- |

| CH02-02 箭落林梢 | 与林荻短暂交手，破坏陷阱后双方被狼群包围 |
| CH02-03 背靠岩壁 | 共同守住狭口，暂时停战；林荻要求检查货箱 |
| CH02-04 破笼空地 | 击退盗猎哨兵，找到被割伤的幼狼和运兽笼 |
| CH02-05 溪边药草 | 保护采药者，清理盘踞药地的巨蛛，给伤者止血 |
| CH02-06 烟火山坡 | 阻止盗猎者继续放火，把狼群与营地隔开 |
| CH02-07 丢失的猎童 | 找到林荻弟弟，护送他经过狼群徘徊的树林 |

**章末**：林荻检查货箱后道歉，送弟弟到安全村庄再同行。动物危机解除，却在盗猎营发现画着太阳信物的悬赏页，为追捕埋伏笔。

**最终解释顺序**：先救伤者、停下增援，再由公主保证同伴的人身安全、主角交出武器接受保管；检验未破损的内层任命与国书；用王城副验确认太阳钥印合法；对照盗宝回执和遗迹拓片；接收第九章寄出的信及第十一章军官补报。没有一件突然出现的万能证据，也不靠打赢公主强迫对方相信。

**核心误会揭晓**：沈砚保护的是合法出使信物，公主追的是外形相近的失窃礼器。主角以为追兵阻止和平，公主以为逃跑者准备袭击庆典。双方根据真实但不完整的现场判断，做出了逐渐错误的推论。

**结尾**：公主先为错误追捕致歉，沈砚承认多次突围造成的财物和人员损伤需要处理；各方照料伤员、清点损失。正式会见以简短演出完成，续订商路与救援盟约。重要人物围桌吃饭，互相补上途中没听见的半句话。最后一幕是咕鲁为那枚闹出一路麻烦的钥印做了个醒目的盒子，写上“使者的，别再抢错”。

## 六、每章如何独立，又如何连成一段旅途

- 章首给出地点、队伍、当地难题与当前期限，玩家即使隔几天回来也能理解。章节选择界面显示前情摘要。
- 每章十关具有起承转合，但不固定成九场清怪加一场首领：可以有护送、驱退、救援、守点、追逐和战斗中的机关目标。
- 每关都可有冲突或战斗，剧情通过行进对白、环境与短演出交代，不必制作一整关纯会议。
- 每章第十关完成一个局部目标，同时用短对话回收误会。解除的是当地误会，或者揭示新的事实而加深主线误判。
- 每关结束给出“到了哪里、救了谁、拿到什么、谁误会了谁”的明确变化。重玩章节不改写后续存档中的主线事实。
- 章节可独立载入，主线关键道具与队友状态使用预设保证推进；跨章奖励可以后续设计，不默认必须持有上一章所有物品才可玩。

| 章节 | 当地冲突的结果 | 对贯穿误会的影响 |
| --- | --- | --- |
| CH01 | 哥布林还包、约定赔偿 | 建立第一次先打后解释的模式 |
| CH02 | 猎手和解，狼群获得退路 | 出现太阳失物悬赏 |
| CH03 | 解救咕鲁，突破掠夺队 | 包装损坏、赃物传言让身份可疑 |
| CH04 | 部分守卫被救，局部停战 | 强闯边关记录加重王室怀疑 |
| CH05 | 港口工人与使团和解 | 说明信被截，主角误以为已通知 |
| CH06 | 海盗误劫真相查明，合作救人 | 与海盗同船加深外部误判 |
| CH07 | 失事者停止争水，合作出海 | 伙伴信任上升，出现更多见证者 |
| CH08 | 苇民误认解除，安全穿泽 | 确认通缉已先到前方 |
| CH09 | 与公主短暂合作后分离 | 空匣加深误会，拓片提供解答 |
| CH10 | 抓住真盗贼、保全真失物 | 主角明白全貌，军令仍未撤回 |
| CH11 | 与部分追兵互救 | 正式补报推动最终核验 |
| CH12 | 与皇室交战后互救停手 | 完整核验、解除误会、完成外交 |

## 七、供后续关卡会话使用的约束

1. 采用本文 CH 编号，旧方案 ST01—ST18 与水闸听证主线停止作为设计依据。十二章和每章十关先作为完整候选范围，不表示要求一次全部实现。
2. 每份关卡方案写明：所属章关、入场关系、地图场景、敌人动机、战斗目标、协作角色、胜负与重试、战后新事实、下一关入口。
3. 最终皇室战必须保留；皇室成员暂定公主。她的误判需要在前章铺垫，也必须愿意在安全可核验时纠错。
4. 与公主和普通士兵交战采用非致命表现；真实伤害不能靠结尾笑话抹掉，需有医治、赔偿和问责的简短交代。
5. 不把所有袭击归给瓦伦；狼群、天气、海盗利益和地方习惯都有独立成因。误会解除后也不强制所有敌人加入队伍。
6. 不设置万能真言魔法或随时通讯。官方核验有明确渠道，寄信和报告实际影响后续，避免靠所有人都不说话拖延剧情。
7. 推荐先制作 CH01 的十关作为首章原型：少量林地素材、哥布林与机关可以复用，章末包含完整首领战及和解。此前推荐从断桥渡开始的制作建议随旧结构撤销。
8. 待确认项：是否采用十二章规模、画面风格、每关时长、魔法强度、同伴是否可操作、是否保留具体人名。它们不阻碍先设计第一章。

## 八、营地与轻松片段

- 林荻教咕鲁辨认可食蘑菇，咕鲁坚持“会发光的更贵”，结果被要求先给修船的灯供电。
- 玛琳和岳岚比试打绳结，海盗船结与军用固定结各赢一项，最后一起绑出谁也解不开的包袱。
- 阿朔给大家讲王室近卫严格礼仪，沈砚终于发现，自己第一回边关招手的姿势在当地意味着“过来挑战我”。这个小误会只解释一次冲突，不能代替全部政治与身份原因。
- 决战后公主问为何从不走正门，队伍轮流列举被洪水、狼、海盗、通缉令堵住的正门。她听完先笑，随后安排撤销错误记录，让玩笑有实际回应。
