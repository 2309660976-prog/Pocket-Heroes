## 过渡处理

十处章间连接全部改为按实际图片测量：路口中心、两边轮廓宽度、路面颜色及切线斜率。用具有可变宽度的贝塞尔封闭路面连接，不再用固定宽度线条和人工估计的百分比补路。图片按 1200×600 等比显示，章间保留 160 像素缓冲地形，连接层各向图片内部叠合 40 像素；纵向地色采样与少量不规则色块延续地形。仍是“图片＋连接层”的组合资产，不是可直接硬拼的逐像素无缝图。

桥只保留五处：CH03 峡谷吊桥、CH04 浅滩小桥、CH05 运河桥、CH08 入口短栈桥、CH11 峡谷索桥。海盗章完全改为陆地海湾步道；古城以完整石地、浅裂纹和机关底座表达探索。章间连接均不添加桥或桥板。图像编辑使用内置 imagegen，保持简笔画与基础纹理。

当前已核对十一张背景存在且尺寸一致；Edge 实际页面核对全部十处连接几何、图片加载、滚轮平移 500 像素、鼠标拖动 300 像素及跳转末章 13103 像素，无脚本异常；逐处查看接缝总览，确认路面贯通。未测试手机触屏，未接入 SFML 和关卡节点。部分海陆边界仍为简化地色过渡，不代表真实地貌已经完整重绘。

可复验：
- `python scripts/inspect_map_seams.py`：依赖 Pillow，只读测量图片路口，打印坐标与颜色；图片再编辑后需同步 HTML 内采样数据。
- 以 Node 24 和 Edge 调试端口 9231 运行 `node scripts/verify_map_seams.cjs`：检查实际页面并更新当前预览与接缝总览截图；浏览器必须先用专用配置启动，验证结束会关闭它。
- 打开预览的“检查全部接缝”，巡检十处连接，或在地址后加 `?view=seams`。

第一章样图、旧选关预览和 SFML 源码本次均未改动。
